# About

**Kokogray Lab** is a documentation space for CTF notes, cloud and web security concepts, and practical lessons from authorized lab work.

## What belongs here

Clear explanations, reproducible experiments, useful references, and the reasoning behind a result. An unfinished hypothesis should be labeled as such; a completed writeup should be supported by evidence.

## Responsible learning

All testing should be limited to systems the author owns or has explicit permission to assess. Published notes must not contain live credentials, personal data, or details that violate the rules of an event.

## About the site

The site is built with [MkDocs](https://www.mkdocs.org/) and a custom frontend inspired by the clean, dark GitBook layout in the [provided design reference](https://kabinet.gitbook.io/ctf-writeup/2026/wiz-cloud-security-challenge/happy-birthday).

It is an independently hosted site, not a GitBook service or a copy of the reference author's notebook. The branding, starter content, and implementation belong to this repository; no challenge writeups or logos from the reference are included.

Inter and IBM Plex Mono are locally hosted under their SIL Open Font licenses. The layout supports both light and dark appearance, keyboard navigation, and small screens.

## Source and edits

The Markdown, theme, and deployment workflow are available in the [GitHub repository](https://github.com/EvilzCoder/kokogray-lab). Use **Edit on GitHub** on any page to find its source.
